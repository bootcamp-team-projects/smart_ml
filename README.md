# Smart ML — 머신러닝 및 데이터 분석

Smart 팀 프로젝트의 데이터 분석과 머신러닝 관련 코드를 정리하는 저장소입니다. 최종 서비스와 연동되는 데이터·예측 흐름은 관련 앱, 웹 및 문서 저장소와 함께 확인할 수 있습니다.

## 프로젝트 범위

- 데이터 탐색 및 전처리
- 머신러닝 실험과 평가
- 예측 결과 및 실험 조건 기록
- 서비스에서 활용할 데이터·모델 산출물 준비

각 항목의 구현 여부와 세부 모델은 실제 코드와 노트북을 기준으로 명확히 구분해야 합니다.

## 기술 스택

- Python 기반 분석 환경
- 데이터 처리 및 머신러닝 라이브러리(의존성 파일 기준으로 확정 필요)
- 실험 데이터와 모델 산출물

## 실행 방법

저장소에 포함된 requirements 파일 또는 환경 설정을 확인한 후 가상환경을 구성하고, 데이터 경로와 실험 순서에 따라 노트북·스크립트를 실행하세요. 재현에 필요한 데이터가 별도 저장소에 있다면 해당 경로와 준비 방법을 문서화해야 합니다.
